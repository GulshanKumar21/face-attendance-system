# Face Authentication Attendance System

## 📌 Overview
This project implements a real-time Face Authentication Attendance System using OpenCV and Streamlit.  
It allows users to register faces and mark attendance (Punch In / Punch Out) using a webcam.

## 🚀 Features
- Face Registration using webcam
- Face Recognition using LBPH algorithm
- Punch In / Punch Out attendance
- CSV-based attendance log
- Works on low-end systems (Intel i3)
- Real-time camera input

## 🧠 Technologies Used
- Python 3.13
- OpenCV (Haar Cascade + LBPH)
- Streamlit
- Pandas, NumPy
